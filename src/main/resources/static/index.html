How answer choices work 
{
  "title": "Getting started",
  "description": "A short practice quiz",
  "questions": [
    {
      "question": "Which colors are primary?",
      "options": ["Red", "Green", "Blue", "Purple"],
      "correctAnswers": [0, 2],
      "explanation": "Red and blue are primary colors in the RGB model."
    },
    {
      "question": "How many sides does a triangle have?",
      "options": ["Two", "Three", "Four"],
      "correctAnswer": 1,
      "explanation": "A triangle is a polygon with three sides."
    }
  ]
}

Use zero-based answer indexes: the first option is 0. Use correctAnswer for one answer, or correctAnswers with an array for multiple answers. Every question needs an explanation.
